## 🛠️ Tools I Used
During these challenges, I used different tools to get the job done:
*   **Hashcat & John The Ripper**: For cracking passwords and hashes.
*   **Online Hash Databases**: Like `md5hashing.net` and `hashes.com`.
*   **CyberChef**: For quick data decoding and analysis.
*   **Python 3**: For writing custom decryption scripts.
*   **Basic Linux commands**: `cat`, `find`, `grep`, `tar`, `7z`.
